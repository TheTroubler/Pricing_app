# Моя корзина — Live V0.2

Мобильная PWA для сравнения продуктовой корзины по ВкусВиллу, Ленте, Ozon Fresh, Перекрёстку и Ашану.

## Что уже сделано
- мобильный интерфейс для iPhone;
- компактные разворачиваемые строки «Лучшие варианты по каждому продукту»;
- тестовая корзина: яйца С0 (10 шт), молоко 3,2%, кефир 1%, яблоки, мясные чипсы/сушёное мясо;
- фильтр без свинины;
- фильтр без глютен-содержащих ингредиентов; предупреждение «может содержать следы» допускается;
- цена покупки + нормализованная цена ₽/шт, ₽/л, ₽/кг;
- оптимизация на 1 магазин / максимум 2 / абсолютный минимум;
- PWA: после HTTPS-развёртывания можно добавить на главный экран iPhone;
- backend API `/api/search`;
- ВкусВилл: официальный MCP API;
- Лента / Перекрёсток / Ашан / Ozon: серверный Chromium/Playwright-адаптер с live-поиском по storefront.

## Важное ограничение V0.2
Текущий браузерный адаптер получает живую витринную цену, но не гарантирует, что она уже привязана к конкретному адресу доставки. Поэтому UI помечает результат как `каталог` или `Москва`, а не выдаёт его за адресный остаток. Для ВкусВилла официальный MCP также сам по себе не даёт наличие по конкретному адресу.

Следующий слой — сохранённые пользовательские сессии/адресные зоны каждого магазина. Его лучше добавлять после первого реального запуска адаптеров: сайты могут менять процесс выбора адреса и cookies.

## Локальный запуск на компьютере
Требуется Docker Desktop.

```bash
docker build -t grocery-compare .
docker run --rm -p 8000:8000 grocery-compare
```

Открыть `http://localhost:8000`.

## Развёртывание для iPhone
Проект специально сделан одним Docker-сервисом. Его можно развернуть на хостинге, который поддерживает Docker + Chromium (например Railway/Render/Fly.io). После получения HTTPS URL:

1. Откройте URL в Safari на iPhone.
2. Share / Поделиться.
3. «На экран Домой».
4. Приложение откроется в standalone-режиме.

### Минимальные параметры хостинга
- Dockerfile: в корне проекта.
- Порт: 8000 (или пробросить переменную PORT в команду запуска, если конкретный хостинг требует динамический порт).
- ОЗУ: желательно не меньше 1 GB из-за Chromium.

## Почему нужен backend
Браузер iPhone не может надёжно запрашивать все пять магазинов напрямую: CORS, динамические страницы и антибот-механизмы. Поэтому iPhone общается только с нашим `/api/search`, а адаптеры магазинов выполняются на сервере.
